# Logical Design — Library Management System

## Мета системи
Система управління бібліотекою призначена для автоматизації процесів реєстрації користувачів, пошуку та видачі книг, а також керування адміністративним обліком.

---

## Основні сутності

### 1. User (Користувач)
- **UserID** (PK): Унікальний ідентифікатор користувача
- **Name**: Ім’я користувача
- **Email**: Адреса електронної пошти
- **Phone**: Контактний номер

### 2. Book (Книга)
- **BookID** (PK): Унікальний ідентифікатор книги
- **Title**: Назва книги
- **Author**: Автор
- **ISBN**: Унікальний код книги
- **Category**: Жанр / категорія
- **AvailableCopies**: Кількість доступних примірників

### 3. Borrowing (Замовлення/Позика)
- **BorrowID** (PK): Унікальний ідентифікатор позики
- **UserID** (FK): Користувач, який позичив книгу
- **BookID** (FK): Позичена книга
- **BorrowDate**: Дата замовлення
- **ReturnDate**: Запланована дата повернення

### 4. Admin (Адміністратор)
- **AdminID** (PK): Унікальний ідентифікатор адміністратора
- **Username**: Ім’я користувача для входу
- **Password**: Хешований пароль

---

## 🔹 Зв’язки між сутностями

- Один **користувач** може оформити **декілька замовлень**.
- Одна **книга** може бути позичена **декількома користувачами** в різний час.
- **Адміністратор** має права на зміну бази книг, перегляд позик, а також управління користувачами.

---

## 🔹 Бази даних

- **UserDB**: Зберігає інформацію про користувачів
- **BookDB**: Каталог усіх книг, їх статусів і категорій
- **BorrowingDB**: Історія замовлень і поточні позики
- **AdminDB**: Дані для автентифікації адміністраторів

---

## 🔹 Функціональність системи

### Для користувача:
- Реєстрація / вхід
- Перегляд каталогу книг
- Оформлення замовлення
- Перегляд історії замовлень

### Для адміністратора:
- Додавання/редагування книг
- Керування користувачами
- Перегляд замовлень
- Звітність по позикам

---

## 🔹 Обмеження та правила

- Один користувач може одночасно тримати не більше 3-х книг.
- Книга повинна бути повернена протягом 14 днів.
- При затримці повернення може нараховуватись штраф (не реалізовано на цьому етапі).

---

## 🔹 Можливе розширення:
- Мобільна версія
- Інтеграція з електронною бібліотекою
- Сповіщення про термін повернення
- QR-коди для автоматичної видачі книг
